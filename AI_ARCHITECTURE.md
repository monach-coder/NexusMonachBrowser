# Nexus Intelligence Fabric

## Граница компонентов

- `Nexus.Intelligence.Contracts` — стабильный открытый контракт под GPL-3.0-only.
- `Nexus.Intelligence.Fabric` — открытая реализация исследовательской логики.
- `NexusMonach` — оболочка, WebView2, UI и безопасная управляемая навигация.
- `INexusFabricHost` — узкий мост к локальным моделям и embeddings.

Все три проекта находятся в одном репозитории, собираются одной командой и
проходят один Windows CI. Модульная граница сохранена для тестов, развития и
возможных альтернативных реализаций, а не для сокрытия исходного кода.

Текущий набор операций: обычный поиск с последующим анализом выбранного сайта,
внутренний Nexus Search, глубокий анализ,
углублённый поиск, итоговая сводка агента и маршрутизация локальных моделей.
Deep Page QA, Information Value Radar и дальнейшее связывание графа развиваются
в том же открытом Fabric-проекте.

Пользовательский исследователь называется Nexus Следопыт. Его прозрачная панель
показывает ход и результат анализа выбранного сайта и автоматически скрывается
при уходе на другой домен. Один Crawl Engine
обслуживает общий поиск и каталоги максимум двумя параллельными сетевыми задачами;
граф знаний сохраняет связи между запросом, источниками/товарами и выбранной
страницей без cookies, форм и полного HTML.

Глубокий анализ получает один очищенный документ. Углублённый поиск получает
до семи документов одного origin, собранных управляемой навигацией публичной
оболочки. Сводка агента получает этот же ограниченный набор и собственные
предыдущие выводы. Fabric не получает объект WebView2 и поэтому не
может самостоятельно переходить по ссылкам, нажимать элементы или читать
профиль браузера.

## Принципы

- Ни одна модель не скачивается во время работы браузера.
- Текст страницы, аудио, изображения и граф знаний не отправляются во внешние AI API.
- DOM и содержимое сайтов всегда считаются недоверенными данными.
- Модели не нажимают кнопки, не оформляют заказы и не получают пароли, cookies, токены и тела запросов.
- Тяжёлые компоненты загружаются по требованию и выгружаются после задачи.

## Распределение задач фирменным оркестратором

Пользователь не выбирает модель и не переключает технические режимы. Один запрос
поступает в Nexus Intelligence Fabric, после чего Router разбивает его на
специализированные стадии и запускает только нужные локальные компоненты.

| Компонент | Задачи | Жизненный цикл |
|---|---|---|
| Qwen3 0.6B | извлечение JSON, сравнение товаров, исследовательские сводки, план безопасной навигации | один loopback-only llama-server, одна текстовая задача за раз |
| Whisper base q5_1 | локальное распознавание исходного языка звука активного видео | один loopback-only whisper-server; модель остаётся в памяти, CLI — резерв |
| OPUS-MT mul-en + ko-en + en-ru Q8 | перевод страницы, выделенного текста и реплик видео с разных языков на русский; корейский имеет отдельный маршрут | один постоянный Node/ONNX-процесс, модели загружаются по требованию и переиспользуются |
| multilingual-e5-small | векторы вкладок, Smart Capsules, граф знаний, смысловой поиск | низкоприоритетный фон |
| SmolVLM 500M Q8 | описание фото и визуальные признаки товара/интерфейса | только при выборе изображения |
| Windows SAPI/System.Speech | женская озвучка запуска, загрузок, поиска, перевода и предупреждений | один STA-поток; используется установленный локальный голос Windows |

Локальные HTTP-runtime слушают только случайные loopback-порты. Транспорт
оркестратора запрещает proxy, redirect, DNS-имена и соединения не с loopback IP.
Qwen защищён случайным ключом процесса в заголовке Bearer, а Whisper получает
одноразовый непредсказуемый inference-маршрут. Эти эфемерные значения не
сохраняются на диск и не входят в диагностические события.

Аналитический, переводческий и речевой runtime имеют независимые очереди.
Основной видеоконвейер параллельно читает чистую дорожку HTML5 `captureStream`
короткими фрагментами, Whisper распознаёт исходную речь, OPUS переводит её на
русский, а женский SAPI-голос даёт закадровую озвучку поверх приглушённого
оригинала. Очередь хранит максимум два свежих фрагмента и вытесняет старые,
поэтому задержка не растёт. WASAPI loopback остаётся резервом для несовместимых
плееров и приостанавливается на время речи, исключая самопрослушивание.

Перевод страницы разделён на две границы. Основное поле статьи выбирается из
`article`, `main`, `[role=main]` и типовых article-body контейнеров, очищается от
навигации, рекламы, форм, комментариев и боковых панелей, после чего переводится
в памяти и озвучивается женским SAPI-голосом. В DOM возвращаются только переводы
интерактивных элементов: меню, кнопок, вкладок, подписей и подсказок форм.
Значения полей, пароли, автозаполнение и данные авторизации в этот конвейер не
попадают.

Nexus Voice использует тот же Whisper только после нажатия кнопки микрофона или
при явно включённом режиме «свободные руки». Во втором случае команда принимается
только после локально распознанного слова «Нексус». В приватных окнах микрофон и
озвучка событий отключены. Перед синтезом текст очищается от URL, адресов почты,
токенов и управляющих символов; содержимое форм, cookies и аудиозаписи на диск не
сохраняются. Во время собственной озвучки запись приостанавливается, чтобы не
создавать акустическую петлю.

## Комплекты

`source` содержит весь собственный код и проверки. `Full Offline` дополнительно содержит папку `AI`
с проверенными native runtime и весами. Отсутствие файла показывается пользователю явно;
скрытой сетевой установки и облачного fallback нет.

AI pack устанавливается в исходное дерево только через `scripts/Install-OfflineAiPack.ps1`.
Скрипт требует `checksums.sha256`, блокирует небезопасные относительные пути и сверяет каждый файл.
GitHub workflow Full Offline берёт pack из Release этого же проекта, после чего создаёт готовый архив.

## Патчи безопасности

NuGet и GitHub Actions проверяются Dependabot еженедельно. Семантические patch-обновления могут
перейти в auto-merge только после Windows build. Native AI runtime и веса требуют ручной проверки
лицензии, SHA-256, антивирусного сканирования и набора локальных регрессионных тестов.
