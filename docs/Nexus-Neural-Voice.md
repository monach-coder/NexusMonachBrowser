# Nexus Neural Voice

Nexus Neural Voice — полностью локальный слой русской озвучки для браузера,
перевода страниц и видео. Он не вызывает облачный API и не передаёт текст за
пределы компьютера.

## Конвейер

1. До синтеза единый русский speech frontend раскрывает даты, время, числа,
   единицы измерения, валюты и технические сокращения. Он также применяет
   встроенные произношения Nexus Monach, WebView2, Chromium и других терминов.
2. Тестовая сборка использует русский женский голос `Silero Kseniya V5`.
   Piper и медленный Vosk TTS исключены из основного маршрута.
3. Озвучка выполняется постоянным локальным CPU-worker; Windows SAPI остаётся
   резервом. Браузер не обращается к сетевому TTS.
4. Профили «естественный», «спокойный» и «выразительный» меняют темп и
   вариативность речи, не выдавая один голос за три разных диктора.

## Словарь произношений

Пользовательские исправления хранятся рядом с настройками в
`pronunciation-dictionary.json` (`Data` в portable-режиме или каталог
`NexusMonach` в LocalAppData). Формат — обычный JSON-объект:

```json
{
  "Nexus Monach": "Нексус Монах",
  "мой термин": "нужное произношение"
}
```

Файл ограничен 128 КБ и 256 записями. Он читается только локально и
перезагружается после изменения без перезапуска браузера.

## Piper HD pack

Совместимый локальный пакет имеет следующую структуру:

```text
AI\voice\piper\piper\piper.exe
AI\models\voice\piper-hd\voice.onnx
AI\models\voice\piper-hd\voice.onnx.json
```

Основной Windows-контур использует автономный C++ runtime Piper и русскую
женскую модель Irina Medium. Открытый Python worker остаётся инструментом
совместимости и тестирования. Браузер не скачивает runtime или модель во время
работы и передаёт движку только явный локальный путь. Перед распространением
конкретной модели необходимо
проверить лицензию её исходного датасета, сохранить атрибуцию и закрепить
контрольную сумму. Общая лицензия каталога моделей не заменяет лицензию
отдельного голоса.

## Silero Kseniya test pack

```text
AI\voice\silero\nexus-silero-worker.exe
AI\models\voice\silero-v5-ru\v5_5_ru.pt
```

Worker получает только явный локальный путь к модели, закрепляет диктора
`kseniya` и использует SSML-темп без сетевого поиска моделей. Основной русский
Silero V5 опубликован по CC-NC-BY и поэтому допускается в этой тестовой сборке,
но не должен автоматически попадать в коммерческий релиз без отдельной лицензии.

## Доверие к официальному комплекту

Тестовая portable-сборка включает Silero worker и модель в подписанный манифест
Nexus Guardian. Официальный workflow не должен добавлять этот некоммерческий
пакет без явного решения о лицензировании.

Если проверенного голосового комплекта нет, браузер не скачивает его
самостоятельно и использует системный женский голос Windows как резерв.
