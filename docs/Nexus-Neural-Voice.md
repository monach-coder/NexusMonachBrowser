# Nexus Neural Voice

Nexus Neural Voice — локальный слой русской озвучки для браузера,
перевода страниц и видео. Он не вызывает облачный API и не передаёт
текст за пределы компьютера.

## Конвейер

1. Browser/Fabric передаёт worker только уже очищенную русскую фразу.
2. Постоянный `nexus-voice-worker.exe` держит Vosk TTS и модель в памяти,
   поэтому не загружает её перед каждой репликой.
3. Ответ возвращается по UTF-8 JSON Lines, а временный WAV удаляется
   сразу после воспроизведения.
4. Доступны женские профили `Ирина`, `Наташа` и `Аврора`.

## Доверие к комплекту

Исходники не скачивают runtime или веса при запуске. Full Offline workflow
скачивает закреплённый архив модели, проверяет его SHA-256, собирает
`nexus-voice-worker.exe` из открытого адаптера и выполняет smoke-test синтеза.
После этого `AI\voice` и `AI\models\voice` включаются в подписанный манифест
Nexus Guardian. Подмена worker или модели после релиза не должна незаметно
пройти быструю проверку.

Если проверенного голосового комплекта нет, браузер не скачивает его самостоятельно
и использует системный женский голос Windows как резерв.
