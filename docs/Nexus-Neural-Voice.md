# Nexus Neural Voice

Nexus Neural Voice — полностью локальный слой русской озвучки для браузера,
перевода страниц и видео. Он не вызывает облачный API и не передаёт текст за
пределы компьютера.

## Конвейер

1. До синтеза единый русский speech frontend раскрывает даты, время, числа,
   единицы измерения, валюты и технические сокращения. Он также применяет
   встроенные произношения Nexus Monach, WebView2, Chromium и других терминов.
2. Nexus выбирает лучший установленный движок: Piper HD, проверенный Vosk TTS
   из Full Offline voice-pack, затем локальный женский голос Windows.
3. Постоянный worker держит модель в памяти между репликами. Обмен выполняется
   по UTF-8 JSON Lines, а временный WAV удаляется сразу после воспроизведения.
4. Профили «естественный», «спокойный» и «выразительный» меняют темп и
   вариативность речи, не выдавая один голос за три разных диктора.

## Словарь произношений

Пользовательские исправления хранятся рядом с настройками в
`pronunciation-dictionary.json` (`Data` в portable-режиме или каталог
`NexusMonach` в LocalAppData). Формат — обычный JSON-объект:

```json
{
  "Nexus Monach": "Нексус Монах",
  "мой термин": "нужное произношение"
}
```

Файл ограничен 128 КБ и 256 записями. Он читается только локально и
перезагружается после изменения без перезапуска браузера.

## Piper HD pack

Поддержка Piper отделена от официального Vosk-комплекта. Совместимый локальный
пакет имеет следующую структуру:

```text
AI\voice\nexus-piper-worker.exe
AI\models\voice\piper-hd\voice.onnx
AI\models\voice\piper-hd\voice.onnx.json
```

Открытый исходник worker находится в `AI/adapters/piper_voice_worker.py` и
проверяется с Piper 1.4.2 скриптом `scripts/Smoke-PiperVoice.py`. Самостоятельный
Windows runtime и модель являются частью отдельного совместимого HD-пака:
браузер их не скачивает и не собирает во время работы. Worker принимает только
явный путь к локальной модели и не содержит механизма поиска или загрузки
голосов. Перед распространением конкретной модели необходимо
проверить лицензию её исходного датасета, сохранить атрибуцию и закрепить
контрольную сумму. Общая лицензия каталога моделей не заменяет лицензию
отдельного голоса.

## Доверие к официальному комплекту

Full Offline workflow по-прежнему скачивает закреплённый Vosk-архив, проверяет
его SHA-256, собирает `nexus-voice-worker.exe` из открытого адаптера и выполняет
реальный smoke-test синтеза. Затем `AI\voice` и `AI\models\voice` входят в
подписанный манифест Nexus Guardian.

Если проверенного голосового комплекта нет, браузер не скачивает его
самостоятельно и использует системный женский голос Windows как резерв.
