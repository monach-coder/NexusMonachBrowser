# Nexus Monach Browser 2.9

Nexus Monach — браузер для Windows 10/11 на актуальном Chromium-движке Microsoft Edge WebView2. Код создан с нуля: собственный интерфейс, круглая эмблема, нулевая скрытая телеметрия и сбалансированная защита от отслеживания по умолчанию. Встроенный Tor «Режим След» скрывает IP; полностью локальный AI переводит страницы и дублирует видео на русский; обновления приезжают сами, подписанные и проверенные.

## Установка

- **Лёгкий сетевой установщик** — [`NexusMonach-Setup.exe`](https://github.com/monach-coder/NexusMonachBrowser/releases/latest/download/NexusMonach-Setup.exe) (~68 МБ): ставит ядро для текущего пользователя без прав администратора за секунды; нейросети (2.1 ГБ) подтягиваются по сети в фоне, с проверкой SHA-256 каждого пакета по подписанному ECDSA-манифесту.
- **Полный офлайн-архив** — `NexusMonach-Portable-win-x64.zip` из [Releases](https://github.com/monach-coder/NexusMonachBrowser/releases): все компоненты, включая модели, без сети.
- **Обновления** — автоматические: браузер сам проверяет релизы GitHub не чаще раза в 6 часов, скачивает 76-мегабайтное ядро в фон, проверяет подписи и атомарно применяет при следующем перезапуске. Нейросети переезжают только при смене версий моделей.

## Анонимность: Режим След

Один переключатель в настройках включает многослойный анонимный стек:

- **Tor** — браузер запускает собственный `tor.exe` (SOCKS5 на `127.0.0.1:9051`) и направляет весь трафик через него; строгая приватность, отключение расширений и графа знаний на время режима.
- **Мосты против блокировок Tor** — obfs4, snowflake, meek_lite и webtunnel задаются в настройках строками; браузер сам генерирует torrc и перезапускает Tor с ними, маскируя трафик под обычный TLS.
- **Обёртка через VPN** — при запуске След детектирует системный VPN (WireGuard, OpenVPN, TAP, AdGuard Tunnel и другие) и направляет Tor внутрь туннеля: цензор и провайдер видят только VPN, а не факт использования Tor.
- **Порт-страж (PortGuard)** — без прав администратора гасит утечки внутри браузера: блокирует WebRTC-ICE (реальный IP через STUN), mDNS и SSDP через политику контента, DNS-запросы мимо Tor.
- **Порт-щит (PortShield)** — при каждом запуске браузер сканирует порты машины (IP Helper API) и на сессию закрывает правила файрволом «утекающие» порты локальной сети: mDNS 5353, SSDP 1900, NetBIOS 137–139 (один запрос UAC, правила снимаются при выходе). Порты пользовательских служб (RDP, SMB, VNC) не трогаются — о них браузер сообщает голосом и в Дозоре. Режимы: авто / только уведомлять / выключен.
- **Сетевой Дозор** — активная защита от сканирования: honeypot на семи портах-приманках (2222, 3000, 5000, 6379, 8080, 8888, 27017), обманщик отдаёт сканеру правдоподобные баннеры SSH/nginx/Redis, тарпит удерживает соединение 30 секунд, ARP-страж следит за подменой шлюза, DNS-страж ловит запросы в обход Tor. Каждая угроза озвучивается голосом и пишется в журнал окна Дозора; сканирование своих портов — кнопкой в том же окне.

- **Релейный мост** — каждый работающий браузер с включённым Режимом Следа автоматически работает obfs4-мостом Tor, помогая пользователям цензурных сетей обходить блокировки: адрес публикуется в BridgeDB и попадает только к тем, кто просит мосты. Браузер **никогда не становится выходным узлом** (`ExitPolicy reject *:*` — чужой выходной трафик через вас не идёт). Для доступности моста извне нужен проброс портов 9101–9102 на роутере; за NAT мост честно сообщает об этом в настройках. Отключается одним чекбоксом.

## Автономный AI и перевод

Облачных AI-подключений нет — весь стек работает локально из папки `AI`:

- **Синхронный перевод видео**: браузер скачивает аудиодорожку теневым потоком, распознаёт речь Whisper с точными таймкодами, переводит целыми предложениями OPUS-MT и синтезирует русскую озвучку Silero с подгонкой под слот (до ×1.75 без потери концовок); прижившийся отставший перевод отбрасывается. На нераспознаваемых дорожках — автоматический откат на живой режим.
- **Голосовая озвучка страниц**: главное поле статьи переводится в памяти и читается по-русски; в DOM меняются только элементы управления, введённые значения и пароли не читаются.
- **Голоса**: женский Ксения (Silero) по умолчанию и мужской Евгений (Piper) — выбор при первом запуске и в настройках; русские словарь ударений (3.1 млн словоформ) и восстановление «ё» делают речь естественной.
- **Голосовые уведомления**: загрузки, завершение перевода, сетевые угрозы, обновления и готовность нейросетей озвучиваются голосом — это фирменная функция браузера.
- **Следопыт и Fabric**: локальный исследователь открытой страницы, углублённый поиск по её разделам, товарный режим с реальными карточками, Knowledge Constellation — локальный граф знаний о посещениях, Smart Capsules — смысловая группировка вкладок. Модели: Qwen3 0.6B, Whisper base q5_1, multilingual-e5-small, SmolVLM 500M, три OPUS-MT; всё на `127.0.0.1`, без облачных адресов в коде.

Полная история — в `CHANGELOG.md`; архитектура исследовательского слоя — в `docs/Nexus-Intelligence-Fabric.md`.

## Надёжность и диагностика

- **Nexus Guardian** проверяет подписанный ECDSA-манифест целостности перед каждым запуском: критическое несовпадение блокирует запуск, некритическое — включает безопасный режим.
- **Краш-рапорты — причинные графы**: breadcrumbs, системные события Windows и исключение связываются в направленный граф с вычисляемой корневой причиной; выгрузки в Mermaid/DOT/GraphML рядом с каждым рапортом. **3D-визуализатор** с вращением и ползунком времени (проигрывание каскада отказа) открывается вкладкой из Центра Guardian.
- **Доставка крашей в GitHub Issues** (по согласию пользователя): рапорт становится issue с отрендеренным Mermaid-графом; повторные краши схлопываются в комментарий «+1» по сигнатуре. Санитизатор удаляет URL, историю, cookies, токены и пути до отправки.
- **Ступенчатое восстановление графики**: сбой драйвера → осторожный режим без GPU (AI и голос сохраняются) → выздоровление → автоматический возврат в полный режим с голосовым оповещением.
- **Порт-щит и Дозор** описаны выше, в разделе анонимности.

## Что ещё работает

- единая адресно-поисковая строка: DuckDuckGo, Brave, Startpage, Google, Яндекс, Bing, Mojeek; Nexus Search строит локальную выдачу с проверкой источников;
- сетевая строка статуса: TLS, маршрут, скорость адаптера, PING LAN до шлюза без внешних серверов, сторонние узлы и блокировки; Privacy Dock снизу — полная схема топологии `браузер → маршрут → прокси → интернет → сайт`;
- приватные окна с настоящим InPrivate-профилем; уровни защиты Basic/Balanced/Strict; чистка `utm_*`/`fbclid`/`gclid` и других трекинг-параметров;
- локальная защита от фишинга: смешанные алфавиты, подмена доменов, Punycode, IP-адреса и нестандартные порты;
- защита загрузок: SHA-256, сертификат подписи, репутация WebView2 и локальная проверка Windows Defender;
- Passkeys, Windows Hello и FIDO2 через системный WebAuthn; DevTools по F12 без AI-надстроек;
- прозрачный SSH-терминал через штатный `ssh.exe` с явным портом и без сохранения пароля;
- импорт/управление распакованными Chromium-расширениями; Do Not Track и Global Privacy Control; запрос разрешений на камеру/микрофон/геолокацию; блокировка уведомлений по умолчанию;
- собственный HTTP/SOCKS5-прокси со списком прямых исключений; переносимый режим с профилем в `Data`.

## Почему WebView2

Движок использует актуальный Chromium и обновляется с Evergreen Runtime (в Windows 11 уже установлен), не дублируя движок в каждом архиве. Стандартный User-Agent Edge не подменяется: случайная подмена повышает уникальность отпечатка.

## Честные ограничения

Полная анонимность и полная совместимость одновременно недостижимы. Режим След скрывает IP и маскирует использование Tor, но не меняет TLS-отпечаток и поведение пользователя; для чувствительных сессий включайте его осознанно. Релейный мост полезен другим только при пробросе портов на роутере.

Google запрещает часть OAuth во встроенных WebView: отдельные входы «Войти через Google» потребуют системный браузер — проект не будет обходить это подменой идентичности. Расширения, завязанные на закрытые API Chrome Web Store, могут работать частично; контент-скрипты и сетевые правила — наиболее совместимые типы. Фишинг-защита снижает риск, но не заменяет проверку адреса перед вводом пароля.

## Сборка и релизы

Требования: Windows 10/11 x64, [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0), WebView2 Runtime.

```powershell
# Разработка
dotnet restore NexusMonach.sln
dotnet run --project src/NexusMonach/NexusMonach.csproj

# Быстрая автопроверка без диалогов и звука (режим CI)
dotnet run --project src/NexusMonach/NexusMonach.csproj -- --smoke-self-test

# Переносимая сборка
.\scripts\Build-Portable.ps1                      # девелоперская
.\scripts\Build-Portable.ps1 -OfficialGuardianBuild -PrivateKeyPath .guardian-key/official-v1/integrity-private-key.pem

# Релиз одной командой: версия → сборка → подпись → пакеты → GitHub Release
.\scripts\Publish-Release.ps1 -Version 2.9.5
```

Релизером служит `NexusMonach.exe` (Nexus Guardian), внутренний процесс — `NexusMonach.Browser.exe`. Ключи целостности, Crash Vault и полная проверка — в `docs/Nexus-Guardian.md`.

## Хранение данных

- portable-сборка: `NexusMonach-Portable/Data`; установленная и dev-сборка: `%LOCALAPPDATA%\NexusMonach`;
- граф знаний `knowledge-graph.json` там же; в приватном окне индексация не выполняется;
- краш-рапорты — `%LOCALAPPDATA%\NexusMonach\Guardian\CrashVault` (локально до явного согласия на отправку);
- обновления — `%LOCALAPPDATA%\NexusMonach\Guardian\Updates` (стейджинг до применения).
