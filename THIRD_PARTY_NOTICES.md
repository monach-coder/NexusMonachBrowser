# Сторонние компоненты

Nexus Monach использует или распространяет компоненты, права на которые не
принадлежат проекту. В частности, это может включать Microsoft WebView2,
NAudio, llama.cpp, whisper.cpp, Node.js, Transformers.js и автономные модели
Qwen, Whisper, multilingual-e5, SmolVLM и OPUS-MT.

Автономный голосовой комплект использует Windows C++ runtime Piper 2023.11.14-2
проекта Rhasspy, опубликованный по MIT License, и русскую модель Irina Medium.
Открытый Python worker совместим с Piper 1.4.2 проекта Open Home Foundation,
опубликованным по GPL-3.0, но не является основным Windows runtime. Лицензия
каждого голоса и исходного датасета проверяется отдельно.
Модель с отсутствующими или неясными условиями распространения не должна входить
в официальный релиз только на основании лицензии каталога, где она размещена.

Тестовая сборка с выбранным голосом Kseniya использует русскую модель Silero
TTS V5.5, опубликованную Silero Team по CC-NC-BY. Она предназначена только для
локальной некоммерческой оценки и не должна входить в коммерческий выпуск без
отдельного разрешения правообладателя. Worker и модель не обращаются к сети во
время работы браузера.

Словарь нормативных русских ударений `ru-stress-full.txt.gz` собран из
основного словаря проекта RUAccent (Den4ikAI/ruaccent, Hugging Face
`ruaccent/accentuator`), публикуемого по MIT License. Файл переупакован в
компактный формат «слово + номер ударной гласной»: записи с буквой «ё»
убраны, так как «ё» сама обозначает ударение, а ударение остальных 3,1 млн
словоформ перенесено без изменений.

Специализированный перевод использует совместимые с Transformers.js ONNX-
преобразования `Xenova/opus-mt-mul-en`, `Xenova/opus-mt-ko-en` и
`Xenova/opus-mt-en-ru`, основанные на
моделях Helsinki-NLP/OPUS-MT. Исходные модели опубликованы с лицензией
Apache-2.0; точные ревизии и SHA-256 ONNX-файлов закреплены в release workflow.

Каждый компонент и каждая модель сохраняют собственные условия лицензии,
уведомления об авторских правах и ограничения. GPLv3-лицензия собственного кода
Nexus Monach не распространяется на сторонние компоненты и не ограничивает
права, которые их правообладатели предоставили независимо.

Перед официальным Full Offline релизом сборочный процесс должен:

1. зафиксировать точную версию и SHA-256 каждого runtime и файла модели;
2. включить полученный от правообладателя файл лицензии или ссылку на условия;
3. не переименовывать сторонний компонент в собственную технологию проекта;
4. блокировать релиз при отсутствии обязательного уведомления;
5. отдельно проверять, разрешает ли лицензия распространение весов модели.

Этот файл является индексом, а не заменой полных лицензий. Полные тексты должны
лежать в `THIRD_PARTY_LICENSES` официального релиза.
